Що зроблено:
- Додано один глобальний fetcher для всього бота замість окремих запитів на кожного користувача.
- Додано кнопку/команду зупинки фонової розсилки.
- Інтегровано SQLite:
  - користувачі;
  - мінімальний спред користувача;
  - вибрані біржі користувача;
  - поріг дельти для повторних сповіщень;
  - останній відправлений спред по парі symbol/long/short;
  - тимчасовий blacklist токенів.
- Додано funding у картку сигналу.
- Додано посилання на графік UAINVEST.
- Додано окремий мінімальний спред для кожної біржі:
  - /set_exchange_spread mexc 10
  - /set_exchange_spread bybit 3
  - /exchange_spreads
  - /reset_exchange_spread mexc
- Логіка біржового порогу: для сигналу береться максимум із глобального мінімального спреду, порогу long-біржі та порогу short-біржі.
  Наприклад, якщо mexc=10, то будь-який сигнал з mexc в одній із ніг пройде тільки від 10%.
- Додано захист від Telegram flood control:
  - retry після TelegramRetryAfter;
  - пауза між повідомленнями через SEND_MESSAGE_DELAY_SECONDS;
  - максимум алертів за один цикл через MAX_ALERTS_PER_CYCLE.

Корисні .env параметри:
- TELEGRAM_BOT_TOKEN=...
- TELEGRAM_ALLOWED_USER_IDS=123,456
- VIP_COOKIE=...
- BOT_DB_PATH=bot.db
- FETCH_INTERVAL_SECONDS=15
- SEND_MESSAGE_DELAY_SECONDS=1.1
- FLOOD_RETRY_BUFFER_SECONDS=1.0
- MAX_ALERTS_PER_CYCLE=20

Команди бота:
- /start - запуск і фонова розсилка.
- /spreads - запустити фонову розсилку спредів.
- /stop - зупинити розсилку в цьому чаті.
- /set_spread - змінити глобальний мінімальний спред.
- /set_delta - змінити поріг дельти для повторного сповіщення.
- /exchanges - вибір бірж.
- /config - показати поточний конфіг.
- /blacklist SYMBOL [24h|24|1d|90m] - тимчасово вимкнути токен.
- /unblacklist SYMBOL - зняти блокування токена.
- /blacklist_list - показати заблоковані токени.
- /set_exchange_spread EXCHANGE PCT - встановити мінімальний спред для біржі.
- /reset_exchange_spread EXCHANGE - скинути мінімальний спред для біржі.
- /exchange_spreads - показати біржові мінімальні спреди.

Плани:
1. Додати spot+short spread
2. Додати DEX  пули
3. Додати більше PERP DEXes

- Трек позиції: користувач обирає конкретну пару/сигнал для стеження, бот окремо сповіщає, коли спред стає нижчим за заданий поріг.
- Додатковий сигнал, якщо спред довго стоїть на місці або змінюється через заданий час.
- Можливі окремі пороги не тільки для біржі, а для конкретної пари бірж long/short.
- Atomic write для data.json, щоб бот не читав файл посеред запису.
- Логування помилок fetch_exchange_data замість тихого pass.



Відомі ризики:
- У частині старих текстів у коді ще може бути mojibake після попереднього зламаного кодування.
- Якщо на першому запуску дуже багато нових сигналів, бот тепер розтягне відправку по циклах, а не надішле все одразу.
